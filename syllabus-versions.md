# Syllabus Versions and Site Scope

The syllabus year is the calendar year in which the examination is taken. Check your examination year before using any revision set.

## IGCSE Computer Science 0478

**Site baseline:** Examinations 2026–2028 · Version 5
**Coverage:** Topics 1–10 · Papers 1 and 2

## AS & A Level Computer Science 9618

**Site baseline:** Examinations 2027–2029 · Version 2
**AS coverage:** Sections 1–12 · Papers 1 and 2
**A Level Year 2 coverage:** Sections 13–20 · Papers 3 and 4

Students taking 9618 in an earlier examination cycle must compare this material with the syllabus issued for their own examination year.

[Open the official Cambridge 9618 syllabus](https://www.cambridgeinternational.org/Images/721397-2027-2029-syllabus.pdf)

[Open the official Cambridge 9618 pseudocode guide](https://www.cambridgeinternational.org/Images/721401-2027-2029-pseudocode-guide.pdf)

The 9618 routine `RAND(x)` returns a random real number from `0` up to, but not including, `x`. It is not the same routine as IGCSE 0478 `RANDOM()`, which returns a value from `0` to `1` inclusive.
